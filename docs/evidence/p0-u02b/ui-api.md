# UI frente a API

Chromium usa login real de Auth. Configura Main/fin preferido, plantillas Main/Vocal con dependencia y coach, crea el día y sus participantes y guarda la pausa con recursos y espacios explícitos. La macro, requisitos byItem, catálogos/unidades, técnica y competidoras se crean por APIs oficiales.

Después de guardar fases/conjunta en ambos órdenes por API, los editores existentes se recargan. El de fases cambia realmente el orden interno libre (desseleccionar/reseleccionar una operación) y guarda. El de conjunta retira y crea otra vez los dos peers reales y guarda. Las capturas y las respuestas efectivas se conservan en los recibos. No se parchean botones ni readiness.

Los editores crean IDs aleatorios. Para comparar literalmente bases independientes, el harness restaura por la misma API los IDs declarados de conjunta/pausa y el orden nominal flexible de fases; no importa placements ni cambia semántica física. Los recibos `ui-*-created` muestran la autoridad generada por UI; el input posterior es el builder real tras esa restauración. Los intentos de guardar sin cambios recibieron el guard legítimo correspondiente; no se presentan como una escritura exitosa.

La vista final contiene las tres autoridades guardadas. READY describe esa configuración efectiva, no la prueba matemática de toda posible jornada. Los negativos pueden estar listos para solicitar búsqueda y aun así no tener propuesta.

Esta unidad certifica autoría UI de los editores reutilizados y autoría API de los datos enumerados. No afirma que todos los requisitos de A2 dispongan de editor UI ni que A2 completo pueda introducirse ya desde la App.

La revisión visual adicional conserva capturas por editor en `visual/*-editor.png`, con recibos y manifiesto propios. Repite además los seis Stages positivos y el rechazo integrado; esos seis Stages adicionales no se suman a los 12 de las dos bases frías principales. Las decisiones coinciden literalmente con ellas. Las capturas largas originales muestran READY; se prefieren las capturas por componente para ver las autoridades fuera de pantalla.
