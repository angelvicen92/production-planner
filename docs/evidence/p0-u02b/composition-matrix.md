## Próxima frontera

Se cierra el primer cruce Main/Vocal × macro REQUIRED itinerante fija de U02a. Continúan fuera de esta macro las alternativas any/byType/anyOf complejas, membresía dinámica, transición itinerante positiva, scopes explícitos complejos, transporte, setups, rondas y anclajes compuestos. La coexistencia conjunta de esas familias mantiene sus guards o NOT_TESTED según el contrato de origen.

A2 completo desde UI sigue pendiente. Se conserva la falta de editor genérico de requisitos, rutas asimétricas de coach y atributos como requiresBand, además de las composiciones operativas no certificadas. La pausa nativa permite expresar recursos coach explícitos; no se infiere una comida por usar un plató. El pool A/B y sus transiciones positivas no equivalen a la unidad specific fija probada aquí.

La prioridad posterior vuelve a ampliar causalmente esa cobertura conjunta de configuración mínima desde la App, con jornadas nuevas crecientes; no a optimizar el benchmark histórico importado.
