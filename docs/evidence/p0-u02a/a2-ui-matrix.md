## Obligaciones A2 expresables y todavía no expresables

Son expresables de forma nativa las personas y actividades ordinarias, roles Main/Vocal, coaches concretos, dependencias, IN/OUT, familias de setup, rondas, unidades físicas, operaciones ancladas/independientes, conjunta y macro por fases **dentro de sus respectivas fronteras**. Varias requieren API de producto para autoría de requisitos que aún no tiene editor genérico; no equivalen a «A2 configurable enteramente desde App».

U00y dejaba pendientes pausas coordinadas y la macro nominal de Alfombra. U00z y U01d/f resuelven esos contratos de forma acotada: pausa explícita y macro física fija con recursos cambiantes. La primera intersección aquí demostrada pendiente es **su coexistencia con Main/Vocal en un solo día**. No es necesario reproducir 266 tareas para constatarla.

Siguen sin representación/configuración UI nativa completa las rutas asimétricas de coach y atributos como requiresBand; el editor genérico de alternativas de recursos tampoco está acreditado. La comida del coach se puede expresar mediante la pausa nativa del recurso explícito: falta certificar la combinación A2 y no falta necesariamente otro editor. El pool A/B del A2 requiere selección y transición positiva de 15 minutos, mientras la macro investigada sólo certifica unidad específica con transición explícita cero. La relación entre transiciones independientes y operaciones compuestas debe conservar el contrato, no borrarse para simular A2.

También faltan gates de composición conjunta entre Main, macro, anclajes/agenda independiente, transporte, setups, rondas y comidas. Las cabeceras técnicas A2 no crean tareas adicionales sin obligación explícita (Fuente 06 §8.4). No se infiere ninguna operación por nombre ni se traslada el resultado de un importador al estado de autoría UI.
